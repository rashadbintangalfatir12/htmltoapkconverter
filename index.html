Cara memasang ke ponsel
  1. Ekstrak ZIP, lalu unggah semua isinya ke hosting HTTPS (Netlify, GitHub Pages, Vercel, dsb.).
  2. Buka alamatnya di Chrome Android, ketuk menu ⋮, lalu Instal aplikasi. Di iPhone: Safari, Bagikan, Tambah ke Layar Utama.
  3. Untuk file APK, masukkan alamat situsmu ke pwabuilder.com dan pilih Android.
